# 🎬 MovieBlogger

MovieBlogger is a modern, community-driven movie review platform. It allows movie enthusiasts to discover, review, and discuss films in multiple languages (English, Sinhala, and Tamil). Built with a cinematic dark aesthetic and a warm "projector gold" accent.

## 🌟 About The Project

Our mission is to create the most vibrant and authentic community for movie lovers worldwide. We believe that every film deserves thoughtful discussion and every moviegoer deserves a platform to share their voice.

## 🚀 Features

- **Multi-language Reviews:** Filter and read reviews in English, Sinhala (සිංහල), and Tamil (தமிழ்).
- **TMDb Integration:** Auto-fetches movie details (poster, cast, director, trailer) directly from The Movie Database.
- **User Interactions:** Like, dislike, bookmark, and comment on reviews.
- **Real-time Notifications:** Instant alerts for new comments, replies, followers, and admin messages.
- **Support System:** Live chat widget connecting users directly with administrators.
- **Admin Dashboard:** Full moderation tools to manage users, review reports, and send warnings.
- **Publisher Profiles:** Rich user profiles with custom banners, avatars, and social links.
- **Email Newsletters:** Subscribers receive emails when new reviews are published.

## 🛠️ Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router, React Compiler)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Database & Auth:** [Supabase](https://supabase.com/) (PostgreSQL, Row Level Security, Realtime)
- **Rich Text Editor:** [TinyMCE](https://www.tiny.cloud/)
- **Email Delivery:** [EmailJS](https://www.emailjs.com/)
- **Movie Data:** [TMDb API](https://www.themoviedb.org/documentation/api)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Deployment:** [Vercel](https://vercel.com/)
